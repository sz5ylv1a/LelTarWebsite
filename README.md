# Website for Lel.tar

This is the main website for my passion project game Lel.tar. Created with [Vue.js 3](https://vuejs.org/) + [Vite 8](https://v8.vite.dev/), as well as the following tools and packages:
- [Bootstrap 5.3](https://getbootstrap.com/docs/5.3/)
- [Vue Router](https://router.vuejs.org/)
- [Biome 2.x](https://biomejs.dev/)
